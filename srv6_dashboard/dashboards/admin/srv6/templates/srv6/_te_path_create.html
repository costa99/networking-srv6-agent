{% blocktrans trimmed %} A TE path steers a domain's traffic toward one destination through waypoints, in order. Every node then encapsulates that traffic with a segment list: a SID of each waypoint (its End SID, or its uN SID with microSID encoding), then the destination's End.DT46 SID. {% endblocktrans %}

{% blocktrans trimmed %} The destination is either a host (all of the domain's ports on it) or a single VM port; a port path wins over a host path for that port. Only hosts with a registered SRv6 locator are offered. {% endblocktrans %}

{% blocktrans trimmed %} Without waypoints the path is direct, as if there were none: useful to pin a VM's traffic to the direct route while a host path exists. {% endblocktrans %}
